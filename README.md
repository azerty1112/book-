# 🤖 ChatGPT Proxy on Vercel

واجهة ذكية للاستخدام الشخصي لـ ChatGPT، مبنية بـ Next.js 14 وقابلة للنشر على Vercel بثواني.

## 🚀 النشر السريع (3 خطوات)

### 1. ارفع المشروع على GitHub ثم اربطه بـ Vercel

### 2. قبل النشر - أضف متغير بيئي واحد فقط:

اذهب إلى **Vercel → Project → Settings → Environment Variables** وأضف:

| المفتاح | القيمة |
|---------|--------|
| `JWT_SECRET` | أي نص عشوائي طويل (مثل: `Jd7fK2mP9xQ4zR8wL3nV6yT1bH5cA0eG`) |

**الباقي اختياري ويمكن إعداده من لوحة الإدارة لاحقاً.**

### 3. اضغط Deploy

بعد نجاح النشر:
1. اذهب إلى `/login` وسجّل دخولك بكلمة المرور الافتراضية: **`admin`**
2. في لوحة الإدارة، غيّر كلمة المرور فوراً
3. الصق كوكي جلسة ChatGPT (انظر الطريقة أدناه)
4. اضغط "تحديث Access Token"
5. ارجع إلى `/` وابدأ الاستخدام!

## 💾 ربط قاعدة البيانات (KV / Upstash Redis)

**التطبيق يعمل فوراً حتى بدون KV** (يستخدم ذاكرة مؤقتة)، لكن لحفظ الإعدادات بشكل دائم بين عمليات إعادة التشغيل:

1. في Vercel، اذهب إلى مشروعك → تبويب **Storage** (في الأعلى)
2. اضغط **Create Database**
3. اختر **Upstash Redis (KV compatible)**
4. اختر خطة **Free** واضغط Create
5. سيتم تلقائياً إضافة متغيرات `KV_REST_API_URL` و `KV_REST_API_TOKEN` — لا تحتاج لكتابتها يدوياً!
6. اضغط Redeploy

لوحة الإدارة ستعرض لك تلقائياً حالة الاتصال وتوجّهك للخطوات إذا لم يكن KV مربوطاً.

## 🍪 طريقة الحصول على كوكي الجلسة

1. سجّل دخولك إلى [chatgpt.com](https://chatgpt.com) من المتصفح
2. اضغط F12 لفتح أدوات المطور
3. اذهب إلى تبويب **Application** → **Cookies** → `https://chatgpt.com`
4. ابحث عن كل cookies تبدأ بـ `__Secure-` وانسخها كلها كـ `name=value; name2=value2; ...`
   - أو يمكنك استخدام ملحق **EditThisCookie** لنسخ جميع الكوكيز دفعة واحدة

---

## ⏱ التحديث التلقائي للتوكن (Cron)

بدلاً من Vercel Cron (يتطلب خطة Pro)، استخدم **Namecheap cPanel Cron Jobs** أو أي خدمة cron مجانية مثل [cron-job.org](https://cron-job.org):

- **URL**: `https://your-app.vercel.app/api/cron/refresh?secret=YOUR_CRON_SECRET`
- **Schedule**: كل 6 ساعات (`0 */6 * * *`)

اضف `CRON_SECRET` في متغيرات البيئة لحماية الرابط.

---

## 🔒 ملاحظات الأمان

- **غيّر كلمة المرور الافتراضية (`admin`)** فور أول تسجيل دخول
- استخدم قيمة قوية لـ `JWT_SECRET`
- اضبط `API_ACCESS_KEY` من لوحة الإدارة لحماية الـ API العام
- لا تشارك كوكي الجلسة أو التوكن مع أحد
